# AI Coding Practice

English | [简体中文](ai-coding-practice.zh.md)

The problem of development is not "how to write correct code in one pass" —
it is:

**Under incomplete information, shifting requirements, and growing systems,
keep making change decisions that are verifiable, revertible, and evolvable.**

Two axioms:

1. Correctness is not a property proved once; it is a constraint maintained
   through every change.
2. Let errors surface earlier, cheaper, and more reversibly — and let the same
   class of error be blocked by structure the second time.

Three words unfold from these: decision (drawing boundaries before
generation), verification (approaching truth with evidence after generation),
and constraint escalation (after the stumble, locking what verification found
into structure). They form a loop: verification feeds back into decisions,
and confirmed errors escalate into gates for the next decision.
