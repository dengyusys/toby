# 设计理念

[English](principles.md) | 简体中文

Toby 是一件安静的个人工具,不是营销页面。视觉语言简约、平面,任何效果都得自己挣到存在的理由。本文件是两个 Web 应用 UI 工作的参照;主题的代码层在各自的 `src/index.css`。

## 平面优先,拒绝层次

选中与激活态用**填充和字重**表达——`--accent-soft` 填充(与聚焦光晕同一色 tint)加 `font-medium`——从不用阴影。投影带来的层次感是这个产品不需要的东西。(案例:侧栏选中项去掉了 `shadow-sm`,此后靠填充标记选中。)

## 聚焦是光晕,不是边框

聚焦反馈是 3px 的 `--accent-soft` 柔和光晕(主色 8%),盒式输入共用这一种表达——聊天输入框是它的载体。登录框是下划线式输入:聚焦态是下划线转全强度(`border-foreground`),绝不在裸下划线外画光晕。绝不用全强度的 `--ring` 做聚焦环:浅色主题下它接近纯黑,看上去就是一个生硬的黑框。键盘聚焦必须可见;光晕——或强化的下划线——是它可见的方式,而不是去掉它的理由。

## 只用语义令牌

组件只消费主题令牌(`--background`、`--card`、`--muted`、`--ring`、`--accent-soft`……),绝不写裸颜色值。色板是 shadcn 的 zinc 中性色——黑色主色、不带色相;每个应用的 `index.css` 是该应用唯一的主题源。

## 投影是例外

柔和的低透明度环境光阴影只存在于聊天输入框,沿用 ChatGPT/Claude 的惯例。登录卡片是刻意的扁平——无边框、无阴影的白卡落在 muted 底板上,密码框画成下划线(`border-foreground/40`,聚焦转全强度);带阴影的边框观感发糊,全强度的描边在缩放屏幕上又显得粗。其余一切默认无阴影;要加新的,先在这里写明理由。

## 两个应用,一种语言

PC 和移动端从不共享代码,但共享这套语言。两个组件需要同一种表意时,就用同一种处理;第一个实现为下一个定下模式。
