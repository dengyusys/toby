# 认证域（Auth）：公网单用户访问

[English](auth.md) | 简体中文

> 职责、接口与关键规则;实现细节以代码与测试为准。

## 职责与边界

为一个用户提供 Web 登录。未登录的人不能读取日程、使用记忆、生成提案或确认写入。HTTPS 只负责加密传输,不能代替登录;公网入口保持启用认证。

- **管**:登录/退出/会话查询、统一认证保护、密码哈希、会话过期与吊销、登录限流、脱敏日志。
- **不管**:多用户、注册、找回密码、短信、OAuth、管理员后台、公共分享。

## 核心概念

- 认证由环境变量显式启用(配置密码哈希后生效);未配置时保持本地开发行为,Web 免登录。
- 会话令牌为高熵随机值,服务端只存 SHA-256 摘要与到期时间;内存存储,进程重启全部失效。
- Cookie:HttpOnly、SameSite=Strict,公网部署追加 Secure;客户端 JavaScript 不读取令牌。
- 会话有效期、登录限流、Cookie 安全属性均由 `TOBY_AUTH_*` 环境变量配置(明细随域落地进运维文档)。

## 接口面

均为 JSON;错误包络沿用 server 惯例。

| 方法与路径              | 用途                                     |
| ----------------------- | ---------------------------------------- |
| `POST /api/auth/login`  | 登录建立会话;密码错 401,超限 429         |
| `POST /api/auth/logout` | 吊销会话;未登录也幂等成功                |
| `GET /api/auth/session` | 查询会话;认证未启用返回 `enabled: false` |

## 关键规则

- 认证启用后,除认证域自身的端点(登录、幂等的退出、喂给登录页的会话查询)与 `GET /api/system/health`(Docker healthcheck 目标,不含业务数据)外,一切 `/api/*` 端点都必须携带有效会话。静态页面资源不做服务端门禁——强制边界在 API 层,SPA 由客户端跳转登录页。其余未登录统一 401,百分号编码路径无法绕过守卫。
- Web 收到 401 回到登录页;提案确认请求不自动重试。
- 登录限流按客户端 IP 固定窗口;超限 429 带 Retry-After。
- 不保存明文密码或令牌;密码、令牌、密钥不进源码、Git、配置或日志。
- 服务端与开发端口不对公网开放。
- 认证不改变提案规则:只有用户明确确认的提案才写入。
