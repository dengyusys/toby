# 记忆域（Memory）

[English](memory.md) | 简体中文

> 目标契约(域未实施):职责、接口与关键规则;实现细节以代码与测试为准。

## 职责与边界

对话里说「记住我不吃香菜」,获得记忆提案卡(保存/删除动作),确认后写入 `data/memory.db`。

- 只收影响书童服务的**长期信息**:偏好、约束、个人事实、重要决定、进行中事项。一次性事务归告示板、按日打卡归日程、日记随笔归手账。
- 两个消费方向:各域提案生成前的**混合检索**注入;书童只读工具查记忆。
- 每日首次交互时**情节蒸馏**:翻最近的聊天记录提炼记忆提案,顺带近重复合并。
- **不管**:衰减清理、批量删除提案、记忆页搜索框。

## 核心概念

- 一条记忆 = 键 + 分类(个人/偏好/约束/决定/项目)+ 内容 + 保质期(可空)+ 状态(软删可恢复)。
- importance 评分已退役:排名交给检索,约束类记忆保底随行。
- 嵌入服务可选:未配置则检索降级,进程照常启动。

## 接口面

均为 JSON(context 端点为 text/plain);错误包络沿用 server 惯例。

| 方法与路径                                       | 用途                                            |
| ------------------------------------------------ | ----------------------------------------------- |
| `GET /api/memories`                              | 管理列表(活跃未过期,按更新降序)                 |
| `GET /api/memories/context`                      | 上下文文本;带查询词走混合检索,不带为全量清单    |
| `POST /api/memories`                             | 管理面直写(不经提案)                            |
| `DELETE /api/memories`                           | 软删                                            |
| `POST /api/memories/proposals`                   | 一句话生成记忆提案;无可执行动作则返回追问不出卡 |
| `POST /api/memories/proposals/:id/commit·cancel` | 确认 / 取消                                     |

## 关键规则

- 提案动作只有 upsert / remove;remove 的目标必须在本轮注入的清单内(幻觉防线);删除意图由 AI 判定,不设措辞门禁。
- 检索三路召回(向量/字面/新旧)名次融合取前若干条,约束类保底随行;嵌入失败逐级降级,检索永不阻塞提案。
- 蒸馏在距上次超过 24 小时的当日首条消息前同步执行;水位随提案生成推进,取消过的条目不再重提;蒸馏失败静默跳过。
- 敏感内容(密钥、证件等正则命中)不送外部嵌入服务,仅靠字面检索。
- 记忆内容送外部服务向量化,与对话送 AI 同类暴露级别。
- 蒸馏产物同样走提案核对。
- 提案生命周期：生成不落库、确认幂等、已取消的提案拒绝提交、过期返回 410。
