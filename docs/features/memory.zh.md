# 记忆域

[English](memory.md) | 简体中文

> 活契约：一条记忆是什么、记忆如何进提示词、每次变更怎么落地、以及页面。
> 实现细节在代码与测试里；完整理由见
> [personal-agent-memory](../decisions/personal-agent-memory.zh.md)。

## 这是什么

管家的活记忆：不问自取地学习（静默学习），忘掉不再为真的，并汇报每一次变化。整个域由一条原则统治——AI 可以记、可以忘，但每次变更都留一张回执，用户一句话能否决任何一条。存储是仓储端口背后的一个严格解析的 Markdown 文件，按开放的主题小节组织，一律平等；整本书随每个 agent 的提示词出行。

## 职责与边界

- 拥有 `data/memory/MEMORY.md`——仓库唯一的非数据库存储（一域一库的在册例外），在记忆仓储端口之后；Markdown 文件是它今天唯一的实现，可在 composition root 替换而不动域代码。
- 拥有记忆工具（`remember` / `forget` / `off_record`）、`<memory>` 提示词小节构建器、off-record 会话开关、以及页面 API。
- **不拥有**：事件（笔记和聊天史拥有事件；记忆只持有没有域认领的稳定背景）、检索设施（没有——书永远摊开，模型就地阅读）、以及记忆文件之外的任何写入。

## 核心概念

- 条目：开放主题小节下的一行——没有 id、没有来源、没有时间戳，刻意如此。

```markdown
## 约定

- 咖啡记「饮品」
- 出差期间餐饮记「差旅」 (至 2026-11-30)

## 关于我

- 不吃香菜

## 转账

- 给小王的转账走「人情往来」

## 人物

- 小王:房东
```

- 一条 = 主题 + 正文 + 可选的 `(至 YYYY-MM-DD)` 过期——真实日历日期。`until < 今天`（UTC）即过期。`约定` / `关于我` / `人物` 是家常用词，不是特例；任何主题名都合法（非空、简短、全文件唯一）；人物条目保持 `名字:描述` 的家规写法。
- 解析器是确定性的，且是校验的一部分：解析不了的行拒绝写入；损坏的文件处处被拒（`500 MEMORY_FILE_INVALID`，手工修）——绝不静默修复。欢迎手改文件。
- 一次落地的变更回执：`{action, section, before?, after?, created_at}`——before/after 引用渲染后的文件行。卡片复用聊天提案卡；两个 Web 按域 id `memory` 渲染。

## 怎么读

一条规则，没有分层：每一节的每一条未过期条目写进每一个 agent 的 `<memory>` 小节——聊天、每个写库抽取器、意图分类器、记忆 agent——每次运行现场解析，渲染在 `<rules>` 之后、`<context>` 之前。意图分类器与写库 agent 因此看到同一本书；在场是一致的，相关性的判断属于模型，500 条上限就是书的体量边界。

- 损坏的文件把小节降级为可见占位符（记忆文件当前无法读取）——聊天照常，记忆保持可见的坏。
- 过期条目不进提示词；在页面上就是文件自身的行。

## 怎么写

- 三个工具：`remember` / `forget`（写意图）和 `off_record`。每个会话型 agent（聊天的 none agent、账本的抽取器）都带 remember 和 forget——静默学习搭上正在运行的那个 agent。`off_record` 留在记忆域自己的 agent 上，服务显式的 这通别记 / 可以记了。
- 选小节是模型的第一判断：优先归入明显所属的既有小节，都不搭才开新节，用户的显式指令（记到「工作」里）永远优先。
- 显式记忆句（记住X / 忘掉X / 你记得我什么 / 这通别记）像任何注册域一样路由到记忆能力；记忆 agent 用同一组工具处理。
- 定位旧行：更新和删除带一个关键词，对全部未过期条目正文做子串匹配。恰好一条命中 → 替换或删除；多条 → 拒绝并列出候选（问，绝不猜）；零条 → 忘掉 回答 没有相关记忆，带替换的 remember 当作新追加。纯追加先对整本书查重（相同文本 → 已记得）。
- 每次写入：确定性校验（格式、真实日历日期、小节名规则、替换对重复、上限）→ 一次原子整文件替换（临时文件 + rename）→ 回执。
- 页面不逐条写：改动是聊天一句话或手改文件（diff 就是回执）。页面唯一的写是重置——`POST /api/memory/reset`，一次原子清空，维护动作：不过 off-record 门，文件损坏时也允许（显式丢弃是修复通道，不是静默修复）。
- 上限 500 条：满了就是拒绝加 该忘点什么——绝不静默截断，绝不摘要。
- 不记录：一句话或页面开关标记当前对话；开启期间，每次 `remember` / `forget` 调用在工具层被拒（拒绝对模型和 traces 可见），新会话自动复位。删除不是封禁——重学的条目留新回执。
- 聊天中，运行中落地的 remember/forget 成为 transcript 之后的独立提案卡（静默学习保持可见）；记账响应可携带可选的 `memory_receipts` 边车——没学到东西就不带。

## 页面

管家的备忘录，不是数据库表——页面渲染的就是 `MEMORY.md` 本身：等宽字体块里的 Markdown 源文本，按文件序，磁盘上是什么就是什么。空文件显示空态文案；损坏的文件显示诚实的 `MEMORY_FILE_INVALID` 错误。页面上没有任何编辑——改动是聊天一句话或手改文件。头部两个控件：记忆开关（开启记忆 / 关闭记忆）、重置——两步确认（条目数、不可撤销提醒）后一次原子写清空整本书。

## 接口

除文件读取（`text/markdown`）外全部 JSON；所有路由走会话守卫；错误用服务端标准错误体。

| 方法与路径                    | 用途                                                                  |
| ----------------------------- | --------------------------------------------------------------------- |
| `GET /api/memory/file`        | 文件本身——页面的只读视图                                              |
| `GET /api/memory/off-record`  | off-record 标志                                                       |
| `POST /api/memory/off-record` | 设置标志                                                              |
| `POST /api/memory/reset`      | 清空整本书 → `{reset_at}`（维护写：不过 off-record 门；损坏文件也可） |

| 失败                   | 回应                                              |
| ---------------------- | ------------------------------------------------- |
| 形状或取值违反格式     | `400 INVALID_ENTRY`                               |
| 无匹配条目（并发变更） | `404 ENTRY_NOT_FOUND`                             |
| 多条命中 / 重复行      | `409 AMBIGUOUS_ENTRY`（候选在 message 里）        |
| 已存相同行             | `409 DUPLICATE_ENTRY`                             |
| 达到上限               | `409 LIMIT_REACHED`（该忘点什么？）               |
| MEMORY.md 不可解析     | `500 MEMORY_FILE_INVALID`（手工修，或从页面重置） |

## 不变量

1. 一次写 = 一次校验后的原子整文件替换；没有部分写，没有第二存储。
2. 解析器是校验的一部分；解析不了就拒绝，绝不修复。
3. 每次落地变更都留一张引用文件自身行的回执；替换绝不与旧行共存。
4. 过期条目不进提示词、不进查找；在页面上就是文件自身的行。
5. 工具是唯一的程序化写路径，off-record 期间拒绝；手改文件与页面重置是人的写路径。
6. AI 永远看不见文件路径；工具边界就是全部表面。

## 暂不做

- 任何检索——书永远摊开；没有向量、嵌入、可查询的索引。
- 按域喂送（某小节只进某个域的 agent）：等第二个写库域落地、提示词成本或噪声有需要时再议。
- 否决台账或按主题封禁：删除就是删除；重学由可见性（回执）和一句话删除回应，而非阻止。
- 逐条范围或来源；数据库适配器（端口留着门）。
- 页面内编辑：页面刻意只读——编辑就是一句话或手改文件；表单时代的页面与其写路由是删除，不是封存。
