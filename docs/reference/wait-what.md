Fire the moment the user signals the last message did not land — "wait,
what", 「等等」「没听懂」「再讲一遍」. Stop moving forward; re-pitch.

Re-pitch the message:

- Supply the missing context first — exactly what the reader was missing,
  not a re-explanation of everything.
- Then restate the point in plain language: short sentences, one idea each,
  no undefined term.
- Use the repo's standard terms (the AGENTS.md naming rule, `docs/features/`
  vocabulary); spell out any coinage the first time it appears.

The failure was one of context, not of length: a longer pitch with the same
gap fails the same way.
